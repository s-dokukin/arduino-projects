# Arduino Projects

This repository contains Arduino projects created during my studies and practice.

The projects were developed and tested using Wokwi.

## Projects

### Pulsieren

An RGB LED changes between different colors automatically. The project can be controlled through the Serial Monitor using `ON` and `OFF`.

[View project](./pulsieren)

### Bohrmodul

A simulation of a simple drilling module. It uses a light barrier, control signals, LEDs and an Arduino to control the drilling process.

[View project](./bohrmodul)

## Technologies

* Arduino
* C++
* Wokwi
* Serial communication
* Digital and analog I/O
