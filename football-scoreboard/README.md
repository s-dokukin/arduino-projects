# Football Scoreboard

## Description
An Arduino-based football scoreboard that displays the match time and the current score of two teams on a 16x2 LCD display.

## Features
- Match timer (minutes and seconds)
- Home team and away team score
- Two push buttons to register goals
- Real-time display updates

## Components
- Arduino Uno
- 16x2 LCD Display (I2C)
- 2 Push Buttons

## Technologies
- Arduino (C++)
- LiquidCrystal_I2C Library
- Wokwi
