# Pulsieren – RGB LED with Arduino

This project was created with an Arduino Uno and simulated in Wokwi.

## Description

The project controls an RGB LED and changes its color automatically.

The LED goes through several colors:

* Red
* Orange
* Yellow
* Green
* Cyan
* Blue
* Violet

The animation can be started and stopped through the Serial Monitor by entering `ON` or `OFF`.

## Components

* Arduino Uno
* RGB LED

## Technologies

* C++
* Arduino
* Wokwi

## Files

* `sketch.ino` – Arduino source code
* `diagram.json` – Wokwi circuit configuration
* `wokwi-project.txt` – Wokwi project information

## Wokwi

The project can be simulated online with Wokwi.
